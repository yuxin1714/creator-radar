# P0 第一轮：导航与单条链接格式验证

日期：2026-08-31。状态：本轮完成，等待用户反馈后再继续。

## 本轮成果
- 七个一级页面：/today、/feed、/creators、/works、/creation、/tasks、/settings。
- 统一侧栏、当前导航标识、顶部添加入口、手机折叠菜单。
- 添加弹窗：输入分享文字或完整作品链接，显示加载、成功、失败、短链接待展开状态。
- FastAPI POST /api/v1/links/validate；Next.js POST /api/links/validate 同源代理。
- 抖音 /video/、TikTok /@name/video/、YouTube watch / shorts / embed / live / youtu.be 基础格式识别。
- 规范化作品 URL，移除分享追踪参数；不验证视频真实存在性。
- 平台短链接只识别平台，不展开，不声称已确定为作品；创作者主页给出具体提示。
- API 仅进行纯文本解析，不进行 DNS、外部 HTTP 或媒体下载；拒绝非白名单域名、伪装域名、凭证、异常端口与多链接。

## 明确未实现
账户、作品保存与去重、数据库业务表、真实导入、任务流水线、采集、字幕/转写、AI、创作生成。
页面为真实空态结构，不展示伪造作品、指标或后台任务。仅供本机预览，不用于公网。
详情页面尚未实现，因为尚无持久化业务对象。API_INTERNAL_BASE_URL 可配置服务端代理地址；当前只验证本机前后端模式，未验证完整容器应用 profile。

## 验证记录
- Python unittest：5 组，覆盖三平台、短链接、主页、多 URL、内网地址、伪装域名、凭证及异常格式。
- 前端类型检查与正式构建通过。
- Edge 无头浏览器：桌面 1440px、窄屏 390px。
- 七页导航、实际输入并提交 YouTube 链接、成功结果、错误域名、短链接提示、Escape 关闭、手机导航、横向溢出检查通过；无页面 JS 错误。
- 浏览器测试发现并修正同源校验误拦截；修复后重新构建并完整复测通过。
- 非同源 POST 返回 403；JSON null 输入返回 422。
- 桌面首页和验证结果截图已目视检查；测试工具与截图暂存 F:/DevTools/BrowserCheck，不是产品依赖。

## 用户体验
打开 http://127.0.0.1:3000/today → 右上角“添加” → 粘贴完整作品链接 → 验证作品链接。
可以用自己的公开视频地址；结果不等于作品已保存、可访问或已分析。
