# 团队在线版方案与费用

2026-09-08 用户选择团队在线工作台，暂无服务器；登录采用邮箱 + 密码，不接企业 SSO。本文件为可评审方案，尚未购买资源或向公网部署。

## 推荐起步方案

DigitalOcean 新加坡机房，Linux x86_64，Basic Droplet 4 vCPU / 8 GiB / 160 GiB SSD。官方常规配置当前列价 USD 48/月。首期按 5–10 名轻量协作成员估算；单台服务器承载 Web、API、PostgreSQL、Redis、后台 worker，通过反向代理提供 HTTPS。不是高可用架构，稳定增长后再拆数据库或 worker。

参考选项：

| 方案 | 官方服务器月价 | 适用情况 |
| --- | --- | --- |
| DigitalOcean 2 vCPU / 4 GiB | USD 24 | 小范围界面与 GPT 流程试用，不建议与本地大模型转写同时运行 |
| DigitalOcean 4 vCPU / 8 GiB | USD 48 | 推荐的小团队完整试运行起点；CPU 转写须限并发并实测速度 |
| AWS Lightsail 2 vCPU / 8 GB | USD 44 | 同样可行；内存相近，CPU 数量较少，后续接 AWS 服务更方便 |

官网价格核对日期为 2026-09-08，地区、税费、IPv4、促销和最终结算以购买页面为准。

- DigitalOcean: https://www.digitalocean.com/pricing/droplets
- AWS Lightsail: https://aws.amazon.com/lightsail/pricing/

推荐方案的基础设施预算约人民币 450–650 元/月：服务器为主，另预留数据库异地备份存储、邮件服务、域名摊销等。人民币是预算估算，不是云商报价或实时汇率；域名通常另按年购买。TikHub、公司 GPT、外部 ASR 的用量费未包含，也不能根据成员人数准确估计。

## 转写安排

当前 Windows RTX 转写不会自动随服务器迁移。首期可把 Linux CPU 转写放入独立 worker，使用 int8、单并发，并限制视频长度/队列；不承诺与 RTX 同速。若实测任务量大，再选择按量 ASR 或独立 GPU worker。无需为网页和 GPT 请求先购买整月 GPU。

## 账户与团队数据

采用管理员邀请、邮箱作为账号、密码登录，初期不开放公众自助注册。补齐密码强哈希、服务端会话、HTTPS Cookie、登录限流、邀请有效期、重置密码以及退出失效。邮件发送需域名验证及 SMTP/邮件服务配置。

建议默认权限：管理员管理成员和供应商设置；成员使用作品、分析和创作。团队作品库与 Skill 共享，个人草稿的共享规则上线前明确。所有查询和任务均绑定真实 workspace_id/user_id，不能继续使用硬编码 local-user；对外 API 不接受客户端自行指定任意 owner。

## 现有代码需改造的内容

1. 真实身份认证、团队归属和权限检查。目前后端约 62 处 local-user 引用，需要逐条覆盖 API、后台任务和资源读取，并测试越权路径。
2. 持久化任务队列与调度。当前 FastAPI BackgroundTasks 和单进程 advisory lock 是本地方案；线上应分离 worker/beat，加入任务归属、幂等、重试与状态租约。
3. 版本化数据库迁移和旧数据归属迁移，使用已经验收的备份/隔离恢复工具演练后切换。
4. 重做生产 Docker 构建、安装 ASR 系统依赖、参数化模型/媒体路径；Compose 当前只是本地骨架，不能直接作为生产发布。
5. HTTPS、域名、密钥注入、异地备份、邮件可达性与服务器重启恢复。上线前从目标机实测公司 GPT/TikHub 连通性。
