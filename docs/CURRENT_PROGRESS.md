## 已完成并验证的核心流程

- 作品导入、TikHub 元数据、作品详情、本地逐字稿、GPT 内容分析。
- 创作项目、平台/类型/方向/风格/语言选择、完整 Skill 内容与版本引用、自定义 Skill 管理、远程 TKI 同步。
- 三个创作方向 → 选择方向 → 正文预览；修改意见 → 修订稿预览。两条路径均通过真实公司模型调用验证，只有明确采用才替换编辑器。
- 草稿保存、历史版本、导出、未保存提醒和浏览器暂存恢复。
- 修改意见及作品管理表单刷新恢复；旧版本标签表单需对照确认后才能保存。
- 统一任务中心、持久化 Celery 队列、后台运行状态和重复执行保护；排队任务重启后可继续，执行中意外中断需手动重试。
- 原文保留、独立中英文译稿/分析、语言切换与历史、分段翻译进度；真实英文译稿与英文分析已通过公司模型验证。
- 创作项目草稿/完成/归档/恢复；作品、情报、项目、任务和研究/生成/版本历史分页。
- 远程 Skill 每日自动检查可按来源开关；TKI 已开启，首次真实检查确认最新版本。
- 分析结构与原文引用校验。旧报告部分引文未通过严格匹配，页面会提示；不覆盖旧结果。
- 抖音创作者导入、每日检查、近期作品收录、可筛选情报流与基础今日研究精选。精选仅使用已有分析与匹配原文的证据，不足不凑数。用户指定的柱子哥TzFilm 已收录 23 条作品。
- 生成历史与指定记录链接、阅读型 Markdown 预览、作品收藏/标签/归档恢复/筛选。
- 设置页注册 GitHub Skill、配置匹配条件；创作时可自动匹配并固定实际 Skill 版本。
- 创作者独立详情、数据库备份与隔离恢复演练已完成。最新后端测试 70 项通过。

用户已决定接口付费稍后处理，并选择团队在线版（邮箱 + 密码登录），目前暂无服务器。可行方案与预算见 TEAM_DEPLOYMENT_PLAN.md，尚未购买或公开部署。
