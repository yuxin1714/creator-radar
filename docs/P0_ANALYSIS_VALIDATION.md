# 分析输出与原文证据校验

新增严格结构校验：摘要、开场、结构、要点、评分理由及证据必填；评分须为 0–100 整数；每条引用去掉首尾空白后必须是当前逐字稿的连续原文。新结果通过后标记 schema_version 0.2，否则任务失败并保留旧结果。

旧报告读取时也进行只读核验，页面显示引用是否通过当前校验，并提供重新分析入口。评分更名为 AI 参考评分，明确不代表播放表现或事实真实性。修复重新发起分析后轮询未重新启动的问题。

验证：37 项后端测试、前端类型检查通过。现有真实样本部分引文未逐字匹配，严格校验拒绝该样本符合预期；没有覆盖用户已有报告。该校验仅证明引用出自逐字稿，不证明论点成立或转写本身准确。新模型输出的严格校验通过率仍需积累样本。
