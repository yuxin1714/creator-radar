# 今日情报与情报流纠偏

今日情报不再复用情报流列表。独立 `/api/v1/today` 从近 7 天收录、未归档的本人作品中读取已有分析：结构和原文引用通过校验才进入候选，按现有 AI 参考评分排序，最多选 5 条，不足不凑数。页面展示摘要、评分理由、证据和研究/创作入口；未通过分析的素材放在单独的“下一步研究”，明确不是推荐。

这属于基础精选规则，不是趋势识别、热度排行或新一次模型评审。“近 7 天收录”是透明的本地默认候选范围，不等于最近发布。页面读取不触发供应商调用。

情报流用于主动探索：关键词、创作者、分析状态、发布时间和排序可选。默认最新发布优先、缺失发布时间排后；分别展示发布和收录日期。当前查询最多 200 条，未实现完整服务器分页，限制明确显示。

验证：50 项后端测试通过，覆盖候选范围、所有权、归档、引用不匹配、不足不凑数和前五排序。前端类型检查与生产构建通过；真实页面验证今日空态、情报过滤、390px 无横向溢出。当前真实数据库没有通过引用核验的候选，正确显示无精选；推荐卡片内容逻辑用隔离测试验证，不伪造真实推荐。
