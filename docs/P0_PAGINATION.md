# 列表与历史分页

2026-09-09：作品、情报流、创作项目、任务中心、保存版本、生成记录及研究记录提供翻页。默认每页 20 条，服务端校验页码与页容量；搜索和筛选在截取页面前处理，不限于当前页。范围变化时前端回到第一页。

旧版未带 page 的 API 调用仍保持列表格式及原约定；工作台页面使用带总数、当前页和总页数的新响应。指定历史记录的直接链接可取到当前页之外的记录，不覆盖原稿。

验证：61 项后端测试通过，含 55 条作品、61 条保存版本/生成记录和超过 200 条任务的边界访问、过滤和无效页码。真实浏览器验证 25 条作品的两页、23 条情报的两页、跨页搜索及历史深链接。前端类型检查、生产构建通过。

当前为本地基础分页：部分查询先在服务端聚合/过滤再截取，尚未做大型数据库的查询下推、游标快照或索引性能调优；不声称高并发规模验收。
