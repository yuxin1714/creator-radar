# 统一任务中心

任务中心汇总最近 200 条元数据采集、逐字稿、内容分析、创作方向、正文生成和反馈优化记录。每 5 秒刷新，可按待处理/处理中、失败、完成筛选；原始错误信息保留。采集 RUNNING 映射为展示层 PROCESSING。

任务入口只读取本机用户拥有的作品及创作项目。采集保留原有开始/重试入口，其他类型通过作品或项目重新发起。创作链接打开项目最新预览，并非历史生成记录详情；生成历史查看仍待补充。转写和分析当前每作品一条状态记录，不是完整尝试日志。

验证：32 项后端测试通过，包括四类聚合、状态与阶段、跨用户隔离；前端类型检查、生产构建通过。真实浏览器读取本机 8 条记录，完成筛选数量及详情跳转一致。
