# 远程 Skill 注册与条件匹配

设置页新增 GitHub Skill 注册表单：名称、HTTPS 仓库地址和仓库内 SKILL.md 相对路径。相同仓库/路径去重；注册后手动同步才取得可用内容，后续再次同步使用已有完整文档与版本保留机制。仅注册不克隆、不调用模型。

每个 Skill 可配置平台、内容类型、创作方向、风格条件。同组任一项满足即可，组之间须同时满足；空组不限，全部留空只允许手动选择。匹配组数更多者优先，同优先级按稳定 ID 排序，不声称模型质量排名。仅匹配启用且已有版本内容的 Skill。

创作页保留手动选择，新增“自动匹配（按创作配置）”。TKI 默认匹配故事类型与故事化表达，无专用匹配时回退通用结构借鉴。提交生成时重新匹配，并冻结实际 Skill ID、版本与内容；已生成方向继续沿用当时快照。路由条件单独保存，不改变 Skill 正文版本。

验证：48 项后端测试、前端类型检查及生产构建通过。真实浏览器验证现有远程源去重、匹配条件入口、TKI 自动匹配和通用回退；本轮没有发起模型生成或远程同步。
