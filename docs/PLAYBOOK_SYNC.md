# 远程创作 Skill 同步

在设置页点击同步，将 GitHub 仓库的 SKILL.md 和同目录 references/ 下的 Markdown 文档保存为一份版本内容。生成时读取这份已保存内容；不会执行仓库中的脚本。

提交 SHA 来自实际读取文件的同一个浅克隆，避免远程更新造成 SHA 与内容不一致。版本号为 Git SHA 加 `.b2`，表示包含引用文档的格式；旧的纯 SHA 版本仍然保留，已有生成记录继续读取其固定版本。

最多读取 40 个文档，总计 200 KB。引用文件缺失、路径越界、符号链接或大小超限会中止同步，原有版本不受影响。当前支持 references/ 下的 Markdown 引用，不加载远程网页、二进制资源或脚本。
