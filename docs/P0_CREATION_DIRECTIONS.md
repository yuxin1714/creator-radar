# 三个创作方向与选向生成

2026-09-08：创作项目编辑页新增“生成三个创作方向”。每张卡包含标题、立意、开场及提纲，选择一张后生成正文；保留直接生成草稿入口。

方向与正文均先保存配置再提交任务。方向生成会冻结平台、语言、Skill 完整内容和版本、参考材料、创作想法；选向生成沿用这个快照，并使用当前正文作为已有草稿。若需要新配置，应重新生成方向。

后台拒绝项目的重复运行任务、其他项目的方向以及不完整的选择；模型方向必须符合恰好三项的结构。正文仅作为预览，明确采用后才载入编辑器，保存后写入草稿及版本历史。刷新可恢复最新方向，但历史方向选择入口尚未实现。
