# P0 第四轮：真实作品详情页

日期：2026-09-01

## 已完成

- 作品库标题与“查看详情”进入 `/works/{work_id}`。
- 单条作品 API 校验本机 owner，返回作品、归一化元数据和最新任务；不存在时返回明确 404。
- 详情展示真实封面、标题、平台、作者、作品 ID、发布时间、时长和可用互动指标。
- 指标只展示 Provider 实际返回的字段；缺失字段不补 0。
- 展示 Provider 与采集时间，保留数据来源可追溯性。
- 抖音 CDN 封面由后端按数据库中的作品 ID 代理，限制 HTTPS、公网解析、图片内容类型和 8 MB 大小；不接受用户提供的代理 URL。
- 桌面与 390px 手机布局通过浏览器验证；列表跳转、返回、真实封面加载、404 和无 JavaScript 错误均通过。

## 仍未实现

- 不下载或保存视频/音频媒体。
- 不生成逐字稿、摘要、内容结构、评分或创作建议。
- 不提供作品删除、标签、搜索、筛选或批量操作。
- 封面当前按小时缓存，不做永久媒体归档。
